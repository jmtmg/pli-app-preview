# Contact card

Your PLI contact list is **derived** from your emails: no manual import needed.

## Open

Click a sender's name / avatar in a conversation, or go to the **Contacts** tab.

## What you see

- **Name** + variants (aliases) found across your exchanges
- **Email(s)** and phone if present in detected signatures
- **Organization** if domain recognized or signature parsed
- **Recent exchanges** (list)
- **Shared attachments** (thumbnail grid)
- **Personal notes** (free field, stored on your device / Cloud encrypted)

## Edit

You can override the suggested name, add a note, mark as "VIP". Those changes are **local to your PLI account**, not written back to Google/Microsoft Contacts.

## Multiple addresses

If the same person writes you from multiple addresses (`perso@gmail.com` + `work@company.com`), PLI can merge them:

- Automatically if same name + same origin domain
- Manually via **Merge with…**

## Delete

No, by design. A contact disappears when all their conversations are deleted.
