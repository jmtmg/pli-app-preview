# Contacting support

## Channels

### Beta (M4)

- **Discord #help**: median response time 2 h (9am-7pm CET, Mon-Fri), by the team + peer help from beta users
- **Discord #feedback**: to report bugs / suggest features
- **Email**: support@pli.app (24 working hours)

### Commercial (M5+)

- **In-app chat (Crisp)**: bubble bottom-right, median response 30 min (9am-6pm CET Mon-Fri)
- **Email**: support@pli.app
- **Discord**: exists but community-driven (no SLA)

## What we need to help you fast

- **Error code** or exact message
- **PLI user-ID**: Settings → About → **Copy diagnostic info** (anonymized, just a hash)
- **Provider**: Gmail / Microsoft / other
- **PLI version**: Settings → About → number
- **When**: date + time (~minute precision if possible)
- **Screenshots** if UI involved

## What you can try solo

1. [Gmail sync KO](26-gmail-sync-ko.md)
2. [Send failing](28-send-ko.md)
3. [Search slow](29-search-slow.md)
4. Restart PLI (full quit, not just close the window)
5. Check [status.pli.app](https://status.pli.app) (public incidents)

## Target resolution times (beta SLA)

| Severity | Examples | Response | Fix |
|---|---|---|---|
| P1 (critical) | No access, data loss | 2 working hours | 24 working hours |
| P2 (impact) | Feature down, slowness | 4 working hours | 3 working days |
| P3 (minor) | Friction, typo | 1 working day | Next sprint |

## General feedback (not a bug)

Open the **feedback FAB** (bottom-right inside PLI) → category **suggestion**. Lands directly in our triage pipeline ([FEEDBACK-TRIAGE](../../FEEDBACK-TRIAGE.md) for the team).

## Security / vulnerability

security@pli.app (PGP available on request). We follow responsible disclosure — informal bug bounty during beta, public credit if wanted.
