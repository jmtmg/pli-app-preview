# Keyboard shortcuts

## Core

| Action | Shortcut |
|---|---|
| Compose new | `C` |
| Reply | `R` |
| Reply all | `Shift + R` |
| Forward | `F` |
| Archive | `E` |
| Pin/unpin | `P` |
| Mark read/unread | `U` |
| Snooze 7 days | `S` |
| Search | `Cmd/Ctrl + K` |
| Command palette | `Cmd/Ctrl + /` |
| Next / prev message | `J` / `K` (vim-style) |
| Open message | `Enter` or `O` |
| Back to list | `Esc` |

## Composer

| Action | Shortcut |
|---|---|
| Send | `Cmd/Ctrl + Enter` |
| Discard | `Cmd/Ctrl + Shift + D` |
| Attach | `Cmd/Ctrl + Shift + A` |
| Schedule send | `Cmd/Ctrl + Shift + S` |
| Slash menu | `/` |

## Filters

| Action | Shortcut |
|---|---|
| Humans | `1` |
| Notifs | `2` |
| All | `3` |
| Unread | `Shift + U` |
| Pinned | `Shift + P` |

## Customize

Settings → **Shortcuts**. Remap anything (except `Cmd+C/V/X` which the OS owns).

## Cheat sheet

`?` anywhere → overlay with all shortcuts (context-aware).

## macOS / Windows / Linux

`Cmd` on Mac, `Ctrl` on Windows/Linux, elsewhere identical.
