# Composing a new message

## Shortcut

`C` anywhere in PLI → composer opens.

## Recipient autocomplete

Type a name → PLI suggests from your **derived contacts** ([Contact card](15-contact-card.md)). Most-recently-written float to top.

## Slash commands

Inside the body, `/` opens a menu:

- `/attach` — attach a file
- `/link` — insert link (or paste URL with Cmd/Ctrl+V)
- `/snippet` — canned reply ([Reply](08-reply.md))
- `/sign` — pick a signature ([Signature](11-signature.md))
- `/schedule` — schedule send

## Attachments

Drag-drop into the composer, or `/attach`. Limits: Gmail 25 MB, Microsoft 20 MB. Above that, PLI offers a secure link ([Attachments](10-attachments.md)).

## From

If multiple accounts, pick the sender address at the top. Remembered per thread.

## Plain text vs rich

Default: minimal rich (bold, italic, links, lists). No tables, no inline images (confusion, readers weirdness). Paste from Word → cleaned automatically.

## Save draft

Auto every 3 s. `Esc` keeps draft, doesn't discard.

## Discard

`Cmd/Ctrl + Shift + D` → confirmation dialog (because you'll regret it eventually).
