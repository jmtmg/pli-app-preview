# Fiche contact

Ta liste de contacts dans PLI est **dérivée** de tes mails : aucun import manuel à faire.

## Ouvrir

Clique sur le nom / avatar d'un expéditeur dans une conversation, ou accède via l'onglet **Contacts**.

## Ce que tu vois

- **Nom** + variantes (alias) rencontrés dans tes échanges
- **Email(s)** et téléphone si présent dans les signatures détectées
- **Organisation** si domaine reconnu ou signature parseée
- **Derniers échanges** (liste)
- **Pièces jointes** partagées avec cette personne (grid thumbnails)
- **Notes perso** (champ libre, stocké chez toi / en Cloud chiffré)

## Éditer

Tu peux écraser le nom proposé, ajouter une note, marquer en "VIP". Ces modifs sont **locales à ton compte PLI**, pas écrites vers Google/Microsoft Contacts.

## Contacts multiples

Si la même personne t'écrit depuis plusieurs adresses (`perso@gmail.com` + `pro@entreprise.fr`), PLI peut les fusionner :

- Automatiquement si même nom + même domaine d'origine
- Manuellement via **Fusionner avec…**

## Supprimer

Non, par conception. Un contact disparaît si toutes ses conversations sont supprimées.
