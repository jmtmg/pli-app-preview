# Contacter le support

## Canaux

### Beta (M4)

- **Discord #help** : temps de réponse médian 2 h (9h-19h CET, L-V), par l'équipe + entraide entre beta users
- **Discord #feedback** : pour rapporter bugs / suggérer features
- **Email** : support@pli.app (24 h ouvrées)

### Commercial (M5+)

- **Chat in-app (Crisp)** : bulle en bas à droite, réponse médiane 30 min (9h-18h CET L-V)
- **Email** : support@pli.app
- **Discord** : existe mais communautaire (pas SLA)

## Ce qu'il nous faut pour t'aider vite

- **Code d'erreur** ou message exact vu
- **User-ID PLI** : Réglages → About → **Copier les infos diagnostic** (anonymisé, juste un hash)
- **Provider** : Gmail / Microsoft / autre
- **Version PLI** : Réglages → About → numéro
- **Quand** : date + heure (~minute près si possible)
- **Captures d'écran** si UI impliquée

## Ce que tu peux essayer seul

1. [Sync Gmail KO](26-sync-gmail-ko.md)
2. [Envoi en erreur](28-envoi-ko.md)
3. [Recherche lente](29-recherche-lente.md)
4. Relancer PLI (quit complet, pas juste fermer la fenêtre)
5. Vérifier [status.pli.app](https://status.pli.app) (incidents publics)

## Temps de résolution cibles (SLA beta)

| Sévérité | Exemples | Réponse | Fix |
|---|---|---|---|
| P1 (critique) | Pas d'accès, data-loss | 2 h ouvrées | 24 h ouvrées |
| P2 (impact) | Feature down, lenteur | 4 h ouvrées | 3 j ouvrés |
| P3 (mineur) | Friction, typo | 1 j ouvré | Prochain sprint |

## Feedback général (pas un bug)

Ouvre le **FAB feedback** (coin bas-droit dans PLI) → catégorie **suggestion**. Ça atterrit direct dans notre pipeline de triage ([FEEDBACK-TRIAGE](../../FEEDBACK-TRIAGE.md) côté équipe).

## Sécurité / vulnérabilité

security@pli.app (PGP dispo sur demande). On suit un disclosure responsable — bug bounty informel pendant la beta, on reconnaîtra publiquement si souhaité.
