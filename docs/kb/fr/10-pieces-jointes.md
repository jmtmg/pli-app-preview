# Pièces jointes

## Limites

- Max 25 Mo par mail (limite Gmail + Microsoft)
- Max 10 fichiers par mail
- Types autorisés : tous sauf exécutables (.exe, .bat, .sh)

## Ajouter

Icône 📎 dans le composer. Tu peux aussi :

- Drag-and-drop depuis le Finder / Explorateur
- Coller une image depuis le presse-papiers (`Cmd+V` / `Ctrl+V`)

PLI affiche une **preview** : thumbnail pour les images, icône + extension pour le reste, et la taille.

## Téléversement

- Progression en temps réel
- Annulation possible à tout moment
- PLI retente automatiquement 3 fois en cas d'échec réseau

## Limites dépassées

Au-delà de 25 Mo, PLI te propose :

1. **Google Drive** (pour les comptes Gmail) — lien inséré, le destinataire clique
2. **OneDrive** (pour les comptes Microsoft)
3. **Hors bande** : PLI ne gère pas WeTransfer ou S3 — à ajouter manuellement

## Réception

Les PJ reçues apparaissent dans la conversation. Clic = preview (pour images, PDF, texte). Download via icône 💾.
