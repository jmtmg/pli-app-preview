# Composer un nouveau message

## Où

Bouton **+** flottant en bas à droite. Raccourci : `N` (desktop) ou `Cmd+N` / `Ctrl+N`.

## Étapes

1. Choisis le compte expéditeur (drawer en haut si plusieurs comptes connectés)
2. Tape le destinataire — PLI auto-complète depuis tes contacts
3. Sujet
4. Corps du message
5. Envoi (`Cmd+Enter` / `Ctrl+Enter`)

## Destinataires

- Virgule ou tab pour séparer plusieurs
- Bcc accessible par le menu déroulant "Cc/Bcc"
- Copie à soi-même : icône `+` à côté de l'email émetteur

## Brouillon persistant

Idem réponse : sauvé toutes les 2 s, restauré au retour.

## Envoi planifié

En V1 (M1-M5) : non supporté. Prévu V1.2. Si tu veux envoyer à 8h demain, utilise l'outil natif ou une extension. On y travaille.

## Annuler un envoi

Après clic **Envoyer**, tu as 5 secondes pour cliquer **Annuler** (toast en bas). Au-delà, le mail part.
