# Raccourcis clavier et gestures

## Desktop (PWA)

| Raccourci | Action |
|---|---|
| `Cmd/Ctrl+K` | Ouvrir la recherche |
| `Cmd/Ctrl+N` | Nouveau message |
| `Cmd/Ctrl+Enter` | Envoyer depuis le composer |
| `Cmd/Ctrl+Shift+A` | Archiver la conversation active |
| `Cmd/Ctrl+Shift+U` | Marquer non lu |
| `J` / `K` | Conversation suivante / précédente |
| `E` | Archiver |
| `R` | Répondre |
| `A` | Répondre à tous |
| `F` | Transférer |
| `?` | Afficher les raccourcis |
| `Esc` | Fermer modale / drawer / tour |

## Mobile (gestures)

| Geste | Action |
|---|---|
| Swipe droite (15 %) | Marquer lu |
| Swipe droite (33 %) | Archiver |
| Swipe gauche (15 %) | Marquer non lu |
| Swipe gauche (33 %) | Silence 7 j |
| Appui long | Menu contextuel (épingler, supprimer, étiquettes) |
| Pinch | Zoom corps de message (accessibilité) |

## Personnalisation

Les raccourcis ne sont pas encore personnalisables. Prévu V1.1 sur demande récurrente (remonte si tu veux que ça bouge plus vite).

## Accessibilité

Focus visible partout, `Tab` parcourt les cartes, `Enter` ouvre, `Esc` revient. Pour les lecteurs d'écran, chaque conversation annonce : expéditeur · sujet · date · statut (lu/non lu).
