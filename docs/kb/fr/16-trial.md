# Essai gratuit 14 jours

## Sans carte bancaire

Tu démarres ton trial PLI Cloud sans entrer de CB. 14 jours complets, toutes fonctions P0 + premium (OCR PJ, multi-comptes illimités).

## Ce qui se passe après

- **J-3** : rappel par email (jamais par push, pas intrusif)
- **J-1** : dernier rappel avec CTA "Prolonger avec PLI Plus"
- **J+0 (fin trial)** : PLI passe en mode lecture + CTA upgrade. Aucune donnée n'est effacée pendant 30 jours.
- **J+30** : si toujours pas d'upgrade, tes données en Cloud sont purgées (préavis email x2)

## Si tu upgrades

Aucun interruption. Tu gardes tout. Le jour de l'upgrade devient ton jour de facturation (pas rétroactif).

## Si tu reviens plus tard

Ton compte reste, tes réglages aussi. Reconnecter OAuth suffit à relancer. Les données purgées (après J+30) ne reviennent pas, mais les mails chez Gmail/Microsoft sont intacts — la sync les réimporte.

## Annuler le trial

Juste ne rien faire. Pas de "Annuler" — il n'y a rien à annuler (pas de CB).

## Le trial inclut PLI Local ?

Non. PLI Local est l'offre sur licence (49 € ou 5 €/mois). Le trial couvre PLI Cloud uniquement. Tu peux basculer de trial Cloud vers licence Local sans perte.
