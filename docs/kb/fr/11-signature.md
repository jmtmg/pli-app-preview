# Signature par compte

Chaque compte a sa signature. Si tu as 3 comptes connectés, tu peux avoir 3 signatures distinctes, choisies automatiquement selon le compte émetteur.

## Configurer

**Réglages > Comptes > {compte} > Signature**. Texte brut ou Markdown (rendu → HTML à l'envoi).

Exemple :
```
Jean-Marie Simeoni
JMJ Consulting · Transition & Souveraineté
+33 6 XX XX XX XX · jm@jmjconsulting.fr
```

## Insertion

La signature est insérée **automatiquement** au composer, séparée du contenu par `--` (convention mail).

## Désactiver ponctuellement

Dans le composer, clic icône signature ✍️ → **Retirer pour ce mail**. L'action ne change pas le réglage global.

## Signature images

Les logos / images embarqués ne sont pas encore supportés en V1. En V1.2 prévue. Workaround : utilise un lien vers une image hébergée.

## Par-compte vs par-mail

Si tu veux une signature différente selon le contexte (boulot vs perso), utilise des comptes différents. PLI n'offre pas de "signatures multiples sur un même compte" (choix produit — complexité contre bénéfice).
