# `docs/governance/launch/drafts/`

Tous les **drafts de communication externe** liés au Launch PLI (M5 + Launch S25) sont conservés ici.

## Règles du dossier

1. **Aucun envoi externe tant que la ligne correspondante dans `../publications-log.md` n'est pas `statut=approved` avec signature direction.**
2. Chaque draft porte un bandeau `🚫 NE PAS PUBLIER` en tête et une checklist pré-publication en pied.
3. Tout chiffre cité dans un draft doit être **mesuré sur le binaire intégré** (`release-v1` post integration-sprint). Les chiffres historiques issus de branches M3/M4 isolées sont retirés jusqu'à re-baseline (D5, deadline 2026-05-14).
4. Un draft en cours d'itération peut être commenté en ligne mais ne doit jamais être renommé sans mise à jour de `publications-log.md`.
